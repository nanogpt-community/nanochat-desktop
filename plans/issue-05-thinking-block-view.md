# Issue #5: Add thinking block view

**Issue URL**: https://github.com/nanogpt-community/nanochat-desktop/issues/5
**Status**: OPEN
**Priority**: HIGH

## Description
Need to add the ability to view the thinking/reasoning blocks generated by models that support reasoning (e.g., OpenAI's o1, o3 models, DeepSeek R1, etc.).

## Objective
Implement a UI component to display model thinking/reasoning blocks:
- Detect when a message includes thinking content
- Display thinking blocks in a collapsible/expandable section
- Visually distinguish thinking from the final response
- Allow users to toggle thinking visibility
- Persist user's preference for showing/hiding thinking

## Technical Context
- **File Location**: `src/ui/message_view.py`, `src/ui/chat_view.py`
- **Tech Stack**: GTK4/Libadwaita, Markdown rendering
- **Related Models**: OpenAI o1/o3, DeepSeek R1, Claude with extended thinking
- **API Field**: Messages may have a `thinking` or `reasoning` field separate from `content`

## API Investigation

Need to check how thinking/reasoning is provided by the API:

**Expected API Structure** (may vary):
```json
{
  "id": "msg_123",

  "thinking": "Let me work through this step by step...\n1. First, I need to...\n2. Then, considering...",
```

### Step 2: Create Thinking Block Widget
**Files to create**: `src/ui/thinking_block.py`

Create a custom widget to display thinking content:
```python
import gi
gi.require_version('Gtk', '4.0')
gi.require_version('Adw', '1')
from gi.repository import Gtk, Adw

class ThinkingBlock(Gtk.Box):
    """Widget to display model thinking/reasoning"""
    
    def __init__(self, thinking_content: str):
        super().__init__(
            orientation=Gtk.Orientation.VERTICAL,
            spacing=0
        )
        
        self.thinking_content = thinking_content
        self._expanded = False
        
        self._setup_ui()
    
    def _setup_ui(self):
        # Expander header
        self.expander = Adw.ExpanderRow(
            title="View Reasoning",
            subtitle=f"{len(self.thinking_content)} characters"
        )
        self.expander.add_css_class("thinking-expander")
        
        # Thinking content (in a scrolled window)
        self.thinking_view = Gtk.TextView(
            editable=False,
            wrap_mode=Gtk.WrapMode.WORD,
            monospace=True,  # Thinking often formatted like code
            margin_top=12,
            margin_bottom=12,
            margin_start=12,
            margin_end=12
        )
        self.thinking_view.get_buffer().set_text(self.thinking_content)
        self.thinking_view.add_css_class("thinking-content")
        
        # Scrolled window for long thinking
        scrolled = Gtk.ScrolledWindow(
            max_content_height=300,
            propagate_natural_height=True,
            child=self.thinking_view
        )
        
        # Container for content
        content_box = Gtk.Box(
            orientation=Gtk.Orientation.VERTICAL
        )
        content_box.append(scrolled)
        
        # Add content to expander
        self.expander.add_row(content_box)
        
        self.append(self.expander)
    
    def set_expanded(self, expanded: bool):
        """Set expanded state"""
        self.expander.set_expanded(expanded)
```

### Step 3: Integrate into Message View

```python
class MessageView(Gtk.Box):
    """Display a single message with optional thinking"""
    
    def __init__(self, message: Message):
        super().__init__(
            orientation=Gtk.Orientation.VERTICAL,
            spacing=12
        )
        
        self.message = message
        self._setup_ui()
    
    def _setup_ui(self):
        # Message header (avatar, name, timestamp)
        header = self._create_header()
        self.append(header)
        
        # Thinking block (if present)
        if self.message.thinking:
            thinking_block = ThinkingBlock(self.message.thinking)
            thinking_block.add_css_class("message-thinking")
            self.append(thinking_block)
        
        # Or handle blocks structure
        if self.message.blocks:
            for block in self.message.blocks:
                if block.type == "thinking":
                    thinking_block = ThinkingBlock(block.content)
                    self.append(thinking_block)
                elif block.type == "text":
                    content_view = self._create_content_view(block.content)
                    self.append(content_view)
        else:
            # Standard message content
            content_view = self._create_content_view(self.message.content)
            self.append(content_view)
    
    def _create_content_view(self, content: str):
        """Create the main content view (markdown rendered)"""
        # Use existing markdown rendering logic
        return MarkdownView(content)
```

### Step 5: Add Settings UI
**Files to modify**: `src/ui/settings_window.py`

Add toggle in settings:
```python
class SettingsWindow(Adw.PreferencesWindow):
    def _create_appearance_page(self):
        appearance_page = Adw.PreferencesPage(title="Appearance")
        
        # ... existing appearance settings ...
        
        # Thinking blocks group
        thinking_group = Adw.PreferencesGroup(
            title="Message Display",
            description="Configure how messages are displayed"
        )
        
        show_thinking_switch = Adw.SwitchRow(
            title="Show Reasoning by Default",
            subtitle="Automatically expand model thinking/reasoning blocks"
        )
        show_thinking_switch.set_active(
            self.settings.get_show_thinking_by_default()
        )
        show_thinking_switch.connect(
            "notify::active",
            self._on_show_thinking_toggled
        )
        
        thinking_group.add(show_thinking_switch)
        appearance_page.add(thinking_group)
        
        return appearance_page
    
    def _on_show_thinking_toggled(self, switch, _):
        self.settings.set_show_thinking_by_default(switch.get_active())
```
